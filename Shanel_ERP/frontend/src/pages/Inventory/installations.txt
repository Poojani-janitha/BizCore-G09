How It Works (Professional Approach)
User from PC A uploads image → Saved to server/backend
User from PC B accesses product → Gets URL http://localhost:5000/uploads/product-123.jpg
Any device can access via URL ✅

Key Features
File validation: JPEG, PNG, GIF, WebP only
Size limit: 5MB maximum
Unique names: Auto-generated with timestamp to prevent conflicts
Preview: Shows image before and after upload
Backward compatible: Still accepts imagePath if no file uploaded


For Production (Real-World)
Replace server-based storage with:
    AWS S3 (most popular - $1-5/month)
    Google Cloud Storage
    Azure Blob
    Cloudinary (image-specific with transformations)

These cloud services provide:
    Global CDN (faster delivery worldwide)
    Automatic backups
    Scalability
    Security & access control
